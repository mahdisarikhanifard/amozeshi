# یار معلم (Amozeshi)
دستیار آموزشی فارسی برای معلمان؛ Android / Kotlin / Jetpack Compose.

## امکانات نسخه اولیه
- مدیریت کلاس و دانش‌آموز
- دفتر نمرات با ستون‌های قابل تنظیم
- ثبت دستی نمرات و ورودی گفتار فارسی (نیازمند Speech Recognition دستگاه)
- تحلیل پایه عملکرد هر دانش‌آموز: میانگین، تعداد نمره، بالاترین نمره، نمرات زیر آستانه ۱۲ و نمرات ثبت‌نشده
- قالب اولیه طرح درس و بازکردن جستجوی وب
- ذخیره محلی داده‌ها

## ساخت
با Android Studio و JDK 17، پروژه را باز کنید و Gradle Sync انجام دهید.
GitHub Actions در مسیر `.github/workflows/build-apk.yml` فایل APK را می‌سازد.

## محدودیت‌های نسخه 1.0.0
- دستیار هوش مصنوعی هنوز به سرویس API متصل نشده است؛ فیلد API key در تنظیمات صرفاً placeholder است.
- جستجوی وب به مرورگر هدایت می‌شود و نتایج خودکار استخراج نمی‌شوند.
- تحلیل آموزشی فعلاً بر اساس نمرات ثبت‌شده و قواعد ساده است، نه مدل هوش مصنوعی.
- واردکردن/خروجی Excel، PDF، پشتیبان‌گیری، جدول‌های ضریب‌دار و آزمون‌ساز در این پایه هنوز پیاده‌سازی نشده‌اند.
