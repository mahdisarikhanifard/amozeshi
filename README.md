# یار معلم — نسخه ۱.۱.۰

دستیار آموزشی فارسی برای مدیریت کلاس، ارزشیابی و تولید محتوای آموزشی در Android.

## امکانات
- مدیریت کلاس‌ها و دانش‌آموزان؛ افزودن، ویرایش و حذف
- دفتر نمرات با ستون‌های قابل تنظیم و ثبت نمره دستی یا صوتی
- تحلیل عملکرد فردی و کلاسی، میانگین، وضعیت و نمرات ناقص
- ثبت حضور و غیاب با تاریخ شمسی و گزارش‌گیری
- برنامه هفتگی و خروجی قابل اشتراک
- تولید طرح درس کوتاه و آزمون با Groq Compound و جستجوی وب
- انتخاب نوع، تعداد و دشواری سؤال و ساخت پاسخنامه
- ذخیره محلی اطلاعات و پشتیبان‌گیری خودکار چندنسخه‌ای
- خروجی و بازیابی پشتیبان شامل دانش‌آموزان، نمرات، ستون‌ها، حضور و غیاب، برنامه هفتگی و کلید Groq
- نگهداری کلید API در فضای رمزگذاری‌شده Android Keystore و آزمایش اتصال از داخل تنظیمات

## امنیت و پشتیبان
کلید API روی دستگاه به‌صورت رمزگذاری‌شده نگهداری می‌شود. فایل پشتیبان برای انتقال تنظیمات، کلید API را نیز در خود دارد؛ فایل پشتیبان را محرمانه نگه دارید.

## ساخت APK
با JDK 17 و Gradle 8.10.2، دستور `gradle assembleDebug` را اجرا کنید. GitHub Actions نیز در مسیر `.github/workflows/build-apk.yml` فایل APK را می‌سازد.
